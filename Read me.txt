国内の公立動物園をクライアントに想定し、海外の人気動物園のような訴求力あるサイトへリニューアルするというコンセプト。

## コンセプト

寒冷地の動物を主役に据え、北海道という土地と接続する。目玉はホッキョクグマ。珍しさで引くのではなく、見せ方で「行きたい」と思わせることを狙う。


## 特徴

### スクロール連動のマスコット

ページ全体のスクロール進捗に連動して、ホッキョクグマのキャラクターが画面下部を左端から右端へ横断する。CSS の scroll 駆動アニメーション（`scroll()` タイムライン + `@property` で型宣言した変数）で実装。
同行クマ（動的）**：上記のスクロール連動。コンテンツ位置とは連動しない独立演出

### AI 生成画像

サイト内の画像はすべて Gemini による生成画像。イラスト主体で世界観を統一。

## 使用技術

- HTML / CSS
- BEM によるクラス命名
- CSS カスタムプロパティ
- CSS ネスト
- CSS scroll 駆動アニメーション（`scroll()` / `@property`）

フォントは Montserrat（欧文）+ Noto Sans JP（和文）。

## 動作環境

Firefox を除く最新ブラウザで動作確認済み。scroll 駆動アニメーション非対応のブラウザでは、クマが動かず定位置に表示される（サイトの利用には影響しない）。

## ページ構成

トップページは各ページへの案内ハブとして位置づけ、詳細は下層ページに置く。

| セクション | 内容 |
|---|---|
| ヒーロー | メインビジュアル |
| 帯 | あいさつ・本日の開園時間・チケット導線 |
| 来園案内 | 実務情報への入口 |
| 動物紹介 | ホッキョクグマを筆頭とした図鑑への入口 |
| 動物たちの暮らし | 生態・個性の紹介への入口 |
| 理念 | 園の理念への入口 |
| アクセス | 所在地・交通 |

グローバルナビは「来園案内 / 動物紹介 / 動物たちの暮らし / 理念」の4項目。チケット購入は常駐 CTA としてヘッダーに配置。
