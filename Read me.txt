国内の公立動物園をクライアントに想定し、お役所的で地味な既存サイトを、海外の人気動物園のような訴求力あるサイトへリニューアルするという想定で制作した架空の動物園サイト。
 
---
 
## コンセプト
 
寒冷地の動物を主役に据え、北海道という土地と接続する。目玉はホッキョクグマ。珍しい動物を並べて驚かせるのではなく、見せ方によって「行きたい」と思わせることを狙いとした。
 
ベースにある考え方は、「見せる動物園から、考える動物園へ」。目の前の一頭を知ることが、その動物が暮らす環境や、そこで起きている変化に思いを広げるきっかけになる。そうした静かな導線を、派手さではなく構成と余白で作ることを目指した。
 
モデルサイトとして、オランダの Diergaarde Blijdorp（https://diergaardeblijdorp.nl/en）を参照した。スクロールに応じて画像とテキストが現れる見せ方や、落ち着いたフォントの組み合わせを踏襲しつつ、難しい部分は省き、上記のコンセプトに合わせて独自の要素を加えている。

## マスコット制作の流れ
 
このサイトの世界観を統一しているのが、ホッキョクグマのマスコットである。既製の素材ではなく、次の手順で自作した。
 
1. **手描きの原案**。まず紙にキャラクターのラフを描いた。丸みのある体型と、親しみやすい表情の方向性をここで決めた。
 
   ![マスコットの原案スケッチ](docs/mascot-sketch.jpg)
 
2. **AIによるキャラ化**。この手描きのラフを参照画像として Gemini に渡し、線と塗りを整え、原案の骨格や表情を保ちながらサイトに載せられる品質に仕上げた。
 
   ![キャラ化したマスコット](docs/mascot-logo.png)
 
3. **全体への展開**。仕上げたホッキョクグマのマスコットを基準に、他の動物（ペンギン・エゾシカ・ヒグマ）のマスコットも、同じ画風で生成。動物ごとに絵柄のばらつきがなく、サイト全体のトーンに統一感を出した。
 
マスコットは単なる飾りではなく、サイトの案内役として、閲覧者に来園前の体験を先取りさせる役割を担う。

## 特徴
 
### スクロール連動のマスコット
 
ページ全体のスクロール進捗に連動して、ホッキョクグマのマスコットが画面下部を左端から右端へ横断する。CSS の scroll 駆動アニメーションを使用。
 
クマは二つの役割をこなす。
- ページ左上に常駐するサイトロゴ。全ページ共通。
- 上記のスクロール連動。ページトップへ戻るリンクも兼ねる
 
### スクロール連動の登場演出
 
`view()` タイムラインを用いて、各セクションやカードがスクロールに応じてふわりと浮かび上がる。見出しには、スクロールに合わせて下線が左から引かれ、引き終わりで文字色が差し色へと変化する二段階の演出を加えている。
 
### ライト／ダークモード
 
`color-scheme` と `light-dark()` により、OSの配色設定に追従してライト／ダークが切り替わる。加えて、ヘッダーに手動トグルを置き、利用者が任意に選択できるようにした。選択は保持される。
 
### ページ遷移
 
View Transitions API（`@view-transition`）により、ページ間の移動にスライドとフェードのトランジションを付けている。
 
### チケット購入
 
チケット購入は `<dialog>` 要素で実装。開閉は HTML の `command` / `commandfor` 属性で行い、合計金額の計算にはJavaScriptを使用。

## 使用技術
 
- HTML / CSS / JavaScript
- BEM によるクラス命名
- CSS カスタムプロパティ
- CSS ネスト
- CSS scroll 駆動アニメーション（`scroll()` / `view()` / `@property`）
- View Transitions API（`@view-transition`）
- `color-scheme` / `light-dark()` によるライト／ダークモード
- `<dialog>` + `command` / `commandfor` によるモーダル
- Swiper（ヒーローのカルーセル）
 
JavaScript は、ハンバーガーメニューの開閉、チケット合計金額の計算、テーマの手動トグルに使用。

## ページ構成
 
日本語版（ルート）と英語版（`en/`）の2言語、各8ページで構成される。トップページは各ページへの案内ハブとして位置づけ、詳細は下層ページに置いている。
 
トップページの主なセクションは次の通り。
 
| セクション | 内容 |
|---|---|
| ヒーロー | メインビジュアル（Swiper カルーセル） |
| 帯 | あいさつ・本日の開園時間・チケット導線 |
| 来園案内 | 実務情報への入口 |
| 動物紹介 | ホッキョクグマを筆頭とした動物図鑑への入口 |
| 動物たちの暮らし | 生態の紹介ページへの入口 |
| 理念 | 園の理念への入口 |
| アクセス | 所在地・交通 |
 
グローバルナビは「来園案内 / 動物紹介 / 動物たちの暮らし / 理念」の4項目。「動物紹介」は独立ページを持たず、トップページの動物紹介セクション（`index.html#animals`）へのアンカーとしている。動物個別の4ページ（ホッキョクグマ・ペンギン・エゾシカ・ヒグマ）へは、動物カードの「詳しく見る」から遷移する。チケット購入は常駐 CTA としてヘッダーに配置している。
